# 06 — دليل أصوات الشخصيات

الحالة: **الهيكل والقواعد العامة فقط.** ملفات الشخصيات الفردية تُكتب بعد قراءة حوارها الفعلي من القاعدة — لا قبل.

## قاعدة عامة
نترجم **من يتكلم إلى من، وبأي نية**. لا تُغيّر النية، ولا يُكشف شيء قبل أوانه، ولا تصير النكتة جادة ولا الحياد عدائياً.

## مستويات السجل اللغوي
| الفئة | السمات العربية |
|---|---|
| الملوك والجارلات | فصحى رصينة، جمل تامة، ضمير الجمع للتفخيم حيث يستخدمه الأصل |
| الجنود والحراس | جمل قصيرة مباشرة، أوامر، سخرية جافة |
| العلماء والسحرة | مفردات دقيقة، تراكيب أطول، مصطلحات المسرد بدقة |
| الكهنة | نبرة طقسية، ألفاظ الدعاء والتبجيل، بلا تعابير دينية واقعية خارج عالم اللعبة |
| التجار | ودّ وإقناع، عبارات بيع |
| اللصوص | خفة، تلميح، ألفاظ سوق فصيحة غير سوقية |
| التنانين | جلال وقِدم، جمل قصيرة ثقيلة، ألفاظ لغة التنانين محفوظة كما في المسرد |
| المدنيون الخائفون | تردد، تقطيع، علامات حذف «…» حيث في الأصل |
