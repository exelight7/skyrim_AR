# 08 — سياسة المصطلحات

الحالة: **السياسة معتمدة كمسودة؛ المسرد فارغ** (`03_translation/glossary.csv`). لا ترجمة جماعية قبل اعتماد المسرد الأساسي منك.

## أعمدة المسرد
`term_en, term_ar, category, meaning, context, rationale, alternatives, forbidden_forms, source_ref, status (PROPOSED|APPROVED|DEPRECATED), approved_by, updated`

## قواعد الاختيار
| الفئة | القاعدة |
|---|---|
| أسماء أشخاص | نقل صوتي موحد حسب جدول النقل أدناه |
| أماكن بلا معنى واضح | نقل صوتي |
| أماكن ذات معنى وصفي | قرار لكل **فئة** يُوثق (نقل صوتي أم ترجمة)، ثم يُطبق على الجميع |
| أعراق وفصائل | ترجمة إن كان المعنى عاماً (الإمبراطوريون، الأقزام؟)، نقل إن كان اسماً علماً (Altmer) — يُحسم في الطيار |
| لغة التنانين | نقل صوتي للفظ داخل الصرخة؛ المعنى في الأوصاف والكتب |
| مصطلحات اللعب (Perk، Skill، Enchanting، Smithing) | ترجمة عربية لا نقل |
| عناصر ومواد (Iron, Ebony, Daedric) | المعدن العادي يُترجم، والمادة الخيالية تُنقل |

## جدول النقل الصوتي (مسودة)
| الإنجليزية | العربية |
|---|---|
| a الطويلة / ā | ا |
| th | ث (أو ذ إذا كان مجهوراً) |
| v | ف (لا ڤ، لضمان الخط والبحث) |
| g | غ (أو ج في أسماء محددة يحسمها المسرد) |
| -ia | ـيا |
| أل التعريف | لا تُضاف للأعلام المنقولة |

## الفرض الآلي
`qa` يرفض أي سطر يحتوي المصطلح الإنجليزي ولا يحتوي ترجمته المعتمدة، أو يحتوي صيغة ممنوعة. الاستثناء يحتاج قراراً مكتوباً في `DECISIONS.md`.

## بذرة المسرد
أسماء `FULL` من `.strings` (الشخصيات، الأماكن، العناصر، التعاويذ، المزايا، الصرخات) — نحو 30 ألف مدخل، تُستخلص منها المصطلحات المتكررة والمهمة أولاً.
