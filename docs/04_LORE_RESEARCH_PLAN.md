# 04 — خطة البحث القصصي

الحالة: **لم يبدأ.** لا يُدّعى فهم أي مهمة قبل قراءة نصوصها الفعلية من قاعدة الجرد.

## المصادر بالترتيب
1. **بيانات اللعبة نفسها** (المصدر المؤكد): نصوص المهام (QUST: الأسماء، الأهداف، سجلات المراحل)، الحوار (INFO)، الكتب (BOOK في dlstrings)، أوصاف العناصر والتعاويذ.
2. **UESP** كمرجع ثانوي للتسلسل والفروع والشخصيات — تُسجّل الصفحة والتاريخ لكل معلومة.
3. لا مصادر غير موثقة؛ ولا تخمين للفجوات.

## البنية (`03_translation/lore_database/*.yaml`)
```yaml
id: lore.dragonborn
topic: The Dragonborn (Dovahkiin)
summary_ar: "…"
facts:
  - text: "…"
    source: "game:skyrim|dlstrings|0x…"   # or "uesp:<page>#<section>"
    confidence: confirmed | inferred
terms: [Dovahkiin, Thu'um]
related_quests: [MQ101, MQ102]
```

## المواضيع (بالأولوية)
1. التنانين ولغتهم، ألدوين، الدرغونبورن، الغريبيردز، البليدز.
2. الحرب الأهلية: الإمبراطورية، الستورمكلوك، الثالمور، معاهدة White-Gold.
3. الآلهة: الآيدرا، الدايدرا وأمراؤهم، تالوس.
4. الأعراق والممالك التسع (Holds) وعواصمها.
5. النقابات والفصائل: Companions، College of Winterhold، Thieves Guild، Dark Brotherhood، Bards College.
6. Dawnguard، Dragonborn (Solstheim/Miraak)، Hearthfire، محتويات CC الأربعة.

## لكل مهمة مهمة (`quest_context_database`)
الغرض، الخلفية، الشخصيات وعلاقاتها، تسلسل الحوار، المراحل، الفروع، النهايات، السياق الخفي، المصطلحات اللازمة — كل حقل بمصدره.

## معيار الاكتمال
مهمة «مفهومة» = كل سطور INFO المرتبطة بها مقروءة + المراحل والأهداف مقروءة + الفروع موثقة. يُقاس آلياً من قاعدة السياق.
