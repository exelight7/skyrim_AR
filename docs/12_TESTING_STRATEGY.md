# 12 — استراتيجية الاختبار

## مستويات الدليل
| المستوى | المعنى | مثال |
|---|---|---|
| L1 آلي | اختبار وحدة / roundtrip / عدّ | `test_strings_io.py` (7/7)، roundtrip 30/30 |
| L2 بنيوي | الملفات المبنية: نفس المعرّفات، وسوم سليمة، xTranslator يفتحها | قبل كل إصدار |
| L3 محاكاة | `simulate_render` بالخط الفعلي والعرض الفعلي | لكل سياق واجهة |
| L4 داخل اللعبة | لقطة شاشة من اللعبة | **وحدها تسمح بوصف «مُتحقَّق»** |

## الاختبارات الآلية الحالية
- `python -I -m unittest discover -s 05_tools/tests -v`
- `python -I 05_tools/skyrim_l10n/strings_io.py roundtrip 01_original/1.7.104.0/strings/*`
- `python -I 05_tools/skyrim_l10n/baseline.py --game-dir "<game>" --verify 00_baseline/hashes.json` (يثبت أن اللعبة لم تتغير)

## قائمة اللقطات داخل اللعبة (L4)
القائمة الرئيسية · إنشاء الشخصية (اسم عربي) · ترجمة حوار قصيرة وطويلة · قائمة الحوار مع خيارات · دفتر المهام (الاسم، الوصف، الأهداف) · إشعار HUD · المخزون (اسم ووصف عنصر) · التعاويذ (`<mag>`) · المزايا · الكتاب (عدة صفحات وصور) · ورقة/رسالة بخط اليد · شاشة التحميل · الحدادة/الكيمياء/السحر · الخريطة وأسماء الأماكن · قائمة الإعدادات · رسالة نظام (حفظ/تحميل) · محتوى DLC وCC.

## التشغيل
اللعبة لا تُشغَّل إلا بإذنك، من ملف تعريف MO2 منفصل، وبعد كل اختبار: `baseline.py --verify`.
